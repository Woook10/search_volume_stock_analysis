# search_volume_stock_analysis
Google 검색량과 주가변동의 관계분석

Nasdaq에 상장된 BNAI를 대상으로 Google Trends 검색량이 주가 수익률에 선행하는지 검정한 프로젝트

- 표본 : 2024.03.15 ~ 2026.05.29, 거래일 553일, 검색량 115주
- 도구 : Python(numpy, pandas, statsmodels, scikit-learn, matplotlib

## 분석 구성

| 단계 | 방법 |
|---|---|
| 전처리 | 주별 집계(검정용) / 일별 전진대입(예측용) |
| 선행성 | 교차상관(lag -12~+12), Granger 인과검정(양방향) |
| 이벤트 스터디 | z-score 기반 급증 탐지, 보유기간별 CAR |
| 다변량 | VAR, IRF, FEVD |
| 예측 | Ridge / GBR, 무예측 벤치마크 대비 평가 |

## 주요 결과

- 교차상관은 lag 0에서만 유의(0.484), 시차 구간 전 구간 비유의
- Granger 인과검정에서 양방향 모두 비유의 (F < 1)
- 검색량 급증 12건의 CAR이 전 보유기간에서 비유의 (t = 0.40~0.92)
- 검색량 피처 추가 시 Test RMSE 악화 (Ridge +3.2%, GBR +4.9%)
- 4개 모형 모두 무예측 벤치마크(RMSE 0.215) 미달

[검색량은 수익률과 동시점에서만 연동되며 어느 방향으로도 선행하지 않는다.]

## 방법론

- 주별 SVI의 일별 보간 배제 - 미래정보 유입과 표본 부풀림 방지, 검정은 원자료 유지
- 촐레스키 순서 변경으로 FEVD 간건성 검증 - 검색량 기여율 25.4% → 0.37%
- 순열 중요도로 in-sample gain과 표본 외 기여 분리 - 검색량 피처 7개중 6개 음수
